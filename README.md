# Mark as Watched for YouTube

Firefox add-on (and Chrome extension) that adds **Mark as watched** to YouTube:

1. In the **⋮ menu** of any video card (home, search, sidebar, subscriptions, playlists).
2. As a **button under the player**, next to Share / Save.

Clicking it records the video in your watch history as **100% watched** (full red bar on the thumbnail).

## How it works

`src/content.js` runs in the page (MAIN world) on `www.youtube.com`:

- gets the video's player response: from the open player if it is the current video, otherwise from
  the server-rendered `/watch?v=…` page (`ytInitialPlayerResponse`). The `/youtubei/v1/player` API is
  only a last resort, since it now often rejects requests without a PoToken (`400 Precondition check failed`),
- sends the same stats pings the YouTube player sends: `api/stats/playback` (start) and
  `api/stats/watchtime` with `st=0`, `et=cmt=len`, `final=1`, i.e. "watched from 0 to the end".

No data goes anywhere except youtube.com. You must be signed in to YouTube.

On the watch page the video is paused first: if it keeps playing, the player's own pings
report the real position and overwrite the "watched" state.

## Install in Firefox (128+)

Temporary (for development, removed when Firefox restarts):

1. Open `about:debugging#/runtime/this-firefox`
2. **Load Temporary Add-on…** → pick `manifest.json` in this folder.

Or with web-ext (auto-reloads on change):

```bash
npx web-ext run --source-dir . --url https://www.youtube.com
```

Permanent install requires a signed package: `npx web-ext sign --channel=unlisted` (needs AMO API keys),
or Firefox Developer Edition / Nightly with `xpinstall.signatures.required = false`.

## Install in Chrome (111+)

1. Run `./scripts/build.sh` — it writes an unpacked Chrome copy to `dist/chrome/`
   (same code, manifest without the Firefox-only keys).
2. Open `chrome://extensions`, enable **Developer mode**.
3. **Load unpacked** → pick `dist/chrome/`.

After changing the code, run the build again and press the reload icon on the extension card,
then reload the YouTube tab. (Loading the repo root directly also works; Chrome only warns about
`browser_specific_settings`.)

Works the same in other Chromium browsers (Edge, Brave, Arc, …).

## Build / lint

```bash
./scripts/build.sh
```

Outputs `dist/mark-as-watched-firefox-<version>.zip`, `dist/mark-as-watched-chrome-<version>.zip`
(Chrome Web Store upload) and `dist/chrome/` (unpacked).

```bash
npx web-ext lint --source-dir . --ignore-files scripts dist
```

Icons are generated by `node scripts/make-icons.mjs`.

## Notes

- YouTube changes its DOM often. Menu selectors live in `CARD_SELECTOR` / `findOpenMenuList`,
  the button anchor in `ensureWatchButton` (`src/content.js`).
- The UI is in Vietnamese when YouTube's language is Vietnamese, otherwise English.
- Live streams (no fixed length) cannot be marked.
